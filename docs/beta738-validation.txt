Beta 738 - VOD resume dialog (2026-10-15)

Reproduced on Fire .190 with beta 737: opening Al filo del manana from Peliculas and choosing Continuar / desde el inicio reopened the catalogue over the resume choice.
Cause: ImportedMovies dismissed its dialog and immediately installed modalReturnAction; the asynchronous dismissal callback consumed that new action and reopened the catalogue over the child dialog.
Fix: pass the library dialog to the host and use the existing dismissModalForNextAction transition before assigning the return action and starting the VOD flow. Applies to the shared imported movies/series surface. No playback URLs, DRM configuration, backend or catchup changes.
