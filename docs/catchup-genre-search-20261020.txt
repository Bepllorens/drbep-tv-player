Generos y busqueda - 20/10/2026, desarrollo .185

Generos:
ArchiveQuerySql.GENRES_SEEK salta entre valores distintos del indice scope/genre.
Recorrido SQL unico (misma instantanea); maximo 257 resultados.
Hasta 256 categorias devuelve esa lista ordenada. Si hay mas, o SQLite rechaza
la consulta, se usa GENRES_ALL original. Conserva ambito y exclusion del vacio,
orden binario y cache/TTL/coalescencia actuales. No cambia permisos de generos:
como antes, el desplegable contiene categorias de todo el ambito.
Sin nuevos indices para esta mejora.

Busqueda:
Indice adicional covering scope/day/start/id/channel/end/genre/search.
Solo se crea con -PupdateChannel=beta -PcatchupSearchIndex=true.
Desactivado por defecto. No cambia instr, normalizacion ni SQL de busqueda.
Sin version nueva del esquema ni migracion de filas. Se crea una vez al abrir;
la apertura posterior verifica IF NOT EXISTS. Fallo de creacion conserva las
consultas existentes. El indice YA CREADO persiste al desactivar la opcion:
SQLite puede seguir usandolo y manteniendolo. Para retirada completa hay que
eliminar exclusivamente programs_search, en una operacion autorizada aparte.
No se ha instalado esta variante ni creado indice en dispositivos de usuario.
