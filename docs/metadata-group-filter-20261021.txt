Problema
El predicado comun por grupo mezclaba identidad de pelicula y nombre de serie
mediante OR. Cuando el tipo ya es conocido puede impedir aprovechar la busqueda
por identidad/ocurrencia y recorrer muchas entradas del grupo.

Cambio
MetadataIndexSelection.groupPredicate(alias,kind) mantiene exactamente el mismo
EXISTS y sus controles de generacion, fuente, tipo, grupo y ocultacion.
Para movie usa identidad+ocurrencia; para series usa nombre de serie.
Tipo mixto conserva GROUP_SQL anterior. Alias/tipos se validan; el grupo sigue
siendo parametro. MetadataIndexQueue usa el tipo conocido de cada repositorio.
No modifica esquema, indices, fuentes, peticiones, resultados almacenados ni DRM.

especializada antes/despues de ocultar episodios y cambiar generacion activa.

El ensayo aislado compara misma cola ligera con filtro anterior/nuevo; las
columnas before_ms y after_ms tambien comparan contra consulta visual historica.
Usar queue_previous_group_ms contra after_ms para aislar este bloque.
