Cambio
La limpieza de generaciones antiguas y la insercion de peliculas/series se
ejecutan dentro de una unica transaccion SQLite. La marca prepare=false se
guarda solo despues de endTransaction correcto.
Si reconstruccion falla o el trabajo se detiene antes de confirmar, rollback
conserva la cola anterior. Si falla la marca de preferencias tras confirmar
SQL, el error permite reintentar; INSERT OR IGNORE mantiene la idempotencia.
No hay transaccion conjunta SQLite/SharedPreferences: ese intervalo se cubre
con reintento, no con una promesa de atomicidad entre almacenes.
